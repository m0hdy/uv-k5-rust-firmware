# Security

This repository is development work, not a supported or release-ready firmware
product. Its development builds and CI artifacts are unvalidated and must not
be treated as safe to flash.

## Reporting a vulnerability

GitHub private vulnerability reporting is not enabled for this repository, and
no other private disclosure channel is published here. Do not put vulnerability
details, exploit steps, sensitive device data, or identifying information in a
public issue, pull request, or discussion. You may contact the repository
owner through [their GitHub profile](https://github.com/m0hdy) to request a
private reporting route, without including vulnerability details in the
request. Wait for a private route before sharing sensitive information.

## Scope and limitations

There are no supported firmware releases. Development builds are not
hardware-validated or approved for installation. Follow the
[recovery runbook](docs/recovery-runbook.md) for its stated scope and
preconditions; it does not qualify a development build as safe or supported.
