# Code of Conduct

We aim to make this project a respectful, constructive place to collaborate.
Treat people with patience and respect; discuss ideas and code in good faith;
and accept feedback without personal attacks.

Unacceptable behavior includes harassment, discrimination, threats, insults,
deliberate disruption, and publishing another person's private information
without permission. Project maintainers may remove content or restrict
participation when needed to protect the community.

## Reporting

Do not post personal or sensitive details in public issues or pull requests.
The repository does not currently publish a private conduct-reporting
channel. You may contact the repository owner through
[their GitHub profile](https://github.com/m0hdy) to request a private route,
without including report details in the public request. Do not disclose a
private report publicly.
